# Phishing Awareness Simulation Using Social Engineering Techniques

## Project Overview

This project demonstrates a phishing awareness simulation developed for educational and cybersecurity awareness purposes. The project simulates a phishing email attack and a fake login webpage to study user awareness regarding phishing threats and social engineering techniques.

## Objectives

* Understand phishing attack techniques
* Simulate phishing email scenarios
* Create a fake login webpage for awareness purposes
* Analyze user behavior toward phishing attacks
* Promote cybersecurity awareness and safe online practices

## Technologies Used

* HTML
* CSS
* JavaScript
* Visual Studio Code
* GitHub Pages
* Google Forms

## Features

* Simulated phishing login webpage
* Educational awareness popup
* Fake phishing email template
* Google Form awareness survey
* GitHub-hosted live website
* Survey response analysis
